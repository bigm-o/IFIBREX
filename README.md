# iFibre — coming soon

Static site, no build step. `index.html` lists the three coming-soon options; each `option-N/` folder is a self-contained page.

- **option-1** — live 3D junction block (three.js, loaded from jsDelivr)
- **option-2** — Blender-rendered glass Africa loop with an interactive data-pulse overlay
- **option-3** — Blender-rendered fibre cables that snake in from the screen edges (`media/intro.*`, plays once), then a seamless loop of light pulses and data packets (`media/loop.*`)

**Deploy on GitHub Pages:** Settings → Pages → Deploy from a branch → `main` / root.
To launch a single option at the domain root, copy that option folder's contents to the root.
